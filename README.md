After downloading, follow these steps to run **Spesialpensum-Linux**:

1. Locate the downloaded file in your downloads folder.
2. Open a terminal window.
3. Navigate to the folder where you downloaded the file. You can do this by typing `cd Downloads` and pressing Enter.
